# Website Tin tức (React + Vite + React Router)

Project LAB LR6 - React Router.

## Chạy project
```bash
npm install
npm run dev
```
Mở http://localhost:5173 (trên Codespaces: bấm "Open in Browser" ở thông báo cổng 5173).

## Các trang
- `/` Trang chủ
- `/news` Danh sách tin tức (có form thêm tin)
- `/news/:id` Chi tiết tin tức
- `/about` Giới thiệu
- `/contact` Liên hệ
